# Flood Loss Analysis Dashboard

## Project Overview

This project analyses flood losses in Malaysia from 2021 to 2025 using Power BI.

## Tools Used

- Microsoft Power BI
- Excel
- DAX

## Key Features

- Total flood losses
- Year-over-year trends
- Regional analysis
- Interactive dashboard

## Skills Demonstrated

- Data Analysis
- Data Visualisation
- Dashboard Development
- Business Intelligence
